## 六、数据使用注意事项

### 6.1 精度与误差

1. **标准误（SE）**：基于独立重复计算，反映蒙特卡洛误差
2. **理论值（th）**：来自预注册表，运行前确定
3. **通过判据**：通常要求 |经验值-理论值| < 2×SE 或 < 1%

### 6.2 整数边界协议

- 所有涉及权重的实验严格遵守整数-小数分解
- 禁止从浮点Nw_i恢复λ_i
- 精确均匀权重构造：λ_i=1, k_i=1, u_i=0（整数存储）

### 6.3 谱原子处理

- 零原子单独记录为质量
- 不与连续密度混排在直方图中
- 图中用独立点或柱状表示

### 6.4 临界点标注

- E2中c=0.6321和c=1.0为临界点
- 临界附近允许有限尺寸效应（平滑过渡）
- 不拟合临界缩放指数
