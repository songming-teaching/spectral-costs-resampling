## 四、常用理论公式（论文中频繁引用）

### 谱矩公式

```
m₂(pre) = 1 + c·r₂
m₂(multinomial) = 1 + c·(1 + r₂)
m₂(residual) = 1 + c·(r₂ + ū)

其中：
- r₂ = Σw_i² - 1（权重二阶偏差）
- ū = Σw_i·u_i（残差加权均值）
```

### 零质量公式（命题8）

```
ν₀ = P(K_N = 0)  （计数零概率）

μ_Q({0}) = max(0, 1 - (1-ν₀)/c)  （谱零原子，max-atom规则）
```

### 秩阈值（定理12）

```
多项：p_s = 1 - e⁻¹ ≈ 0.6321
残差：p_s = 1

c < p_s: 零原子存在
c > p_s: 零原子消失
```

### ESS公式

```
ESS = N / Σw_i² = N / (1 + r₂)
```

## 五、写作要点提示

### 数值精度表述

- ✅ 使用"标准误"（SE）而非"标准差"
- ✅ 报告格式：经验值±标准误（理论值，偏差%）
- ✅ 通过判据：|经验-理论| < 2SE 或 < 1%

### 临界点表述

- ✅ c=0.6321标注为"多项方案临界"
- ✅ c=1.0标注为"残差方案临界"
- ✅ 临界附近允许有限尺寸平滑过渡
- ❌ 不拟合临界缩放指数

### 谱原子表述

- ✅ "零原子质量"或"μ_Q({0})"
- ✅ 与连续谱分开报告
- ❌ 不混入直方图密度

### 整数边界表述

- ✅ 强调权重整数-小数分解λ_i = k_i + u_i
- ✅ 提及浮点归一化陷阱
- ✅ 引用E4验证

### 求解器可信度

- ✅ 引用stage0七项自检
- ✅ 提及伴随方程正确形式（补充材料S.6）
- ✅ 报告双求解器对照结果
