### 3.2 实验中的重要技术发现

1. **整数边界协议的关键性**（E4）：
   - 必须用整数算术计算R=N-Σk_i
   - 禁止从浮点Nw_i恢复λ_i（会触发假的残差随机化）
   
2. **伴随方程的正确形式**（stage0）：
   - 经典文献形式直接搬用即错
   - 正确路线：u=cm → 解z=-c/u+∫t/(1+tu)η(dt) → 读出e
   
3. **谱零原子与矩阵秩的关系**（E2）：
   - 在高斯单位总体下，rank(S_r) = min(d, M_N) a.s.
   - 零质量 = (d-M_N)₊/d（不应使用任意特征值阈值）
   
4. **ESS的局限性**（E3）：
   - ESS相同不意味着谱性质相同
   - 需要三阶矩m₃来区分零度差异
