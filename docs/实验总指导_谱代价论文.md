**重要教训存档（NOTE_伴随方程形式问题）**：伴随侧有两个易混对象——$W$ 侧模型的伴随变换 $\underline m_W$（经典方程 $z=-1/\underline m+\frac1c\int\frac{t}{1+t\underline m}\nu(dt)$ 属于它）与 $S$ 的伴随律变换 $e=cm+(c-1)/z$。文献形式直接搬用即错；$\eta=\delta_1$ 时多个互不相容形式退化重合，故 MP 恢复测试必要而不充分。正确路线是 (C')+(R)：令 $u=cm$，解 $z=-c/u+\int\frac{t}{1+tu}\eta(dt)$，再经 (R) 读出 $e$。此 NOTE 作为实验记录附录永久存档，并已写入论文补充材料 S.6 的计算注记。

## 3. 环境与工程协议

### 3.1 环境

- venv（Python 3.13 + numpy 2.4 + scipy 1.17）：确认 `import matplotlib` 可用（缺失则安装；缺失时脚本只写 CSV 不出图）。
- numpy 2.x：`ndarray.ptp` → `np.ptp(arr, axis=...)`；`np.trapz` → `np.trapezoid`。
- 先跑本机基准：随机 $800\times800$ `eigvalsh` 计时 20 次取均值，据此决定重复数；不预先承诺总时长。
- 并行暂不启用（规模单线程可承受）；如启用用 `joblib`（sklearn 依赖，已可用），按独立重复并行。

### 3.2 浮点/整数协议（整数边界实验的生命线）

1. 整数部分 $k_i$ 以整数存储；$R=N-\sum_ik_i$ 用整数算术计算；**禁止**从浮点 $Nw_i$ 恢复 $\lambda_i$（$1/N$ 浮点值会把 $\lambda_i=1$ 误降为 $<1$，触发假的残差随机化）；精确均匀分支直接写 `lam=1; k=1; u=0`。
2. E4 端点构造取 $N=2^m$（二进制精确）。
3. 边界敏感实验记录实际送入算法的 $\lambda_i$ 摘要（min/max/与目标的最大偏差）；任何浮点归一化写明执行方式及其对 floor–fraction 对的影响。
4. 配对粒子云：同一重复内 pre/多项/残差共享同一 $X$；置信区间只以独立重复为单位。
5. 全程 float64。

## 4. 求解器与理论曲线的生产纪律

1. **双求解器**：伴随侧 `lsd_ww3`（回归验证件）与协方差侧直接求解器（Definition 1 方程）；同参数对照进入自检。
2. **自检清单（7 项，阻断性）**：$\operatorname{Im}m(z)>0$；方程残差 $<10^{-10}$；大 $|z|$ 处 $zm(z)\approx-1$；$\eta=\delta_1$ 恢复 MP（<1%）；零质量与解析式一致（$<10^{-6}$）；截断与带宽敏感性（报告截去质量与二阶尾矩，不静默归一化）；双求解器内部点偏差 $<2\%$。
3. **理论曲线只用预注册计数律**；如需将经验 $\nu_N$ 代入求解器，图中明确标注为 plug-in prediction（用于分离计数律有限样本误差与变换有限尺寸误差），不与纯理论预测混排。
4. 原子画成独立点/柱，不与连续密度混排；展示窗口注明区间外经验质量。

## 5. 误差指标的分层定义（对应审查要求）

- **Stieltjes 指标 $E_h$**（带宽用 $h$，不用 $\eta$——$\eta$ 已被概率律占用）：写明实部网格范围、网格权重、固定带宽、最大误差还是积分误差、原子是否包含在完整变换内；报告 $h/2$ 敏感性。
- **KS**：不拿原始经验 CDF 与平滑密度积分比较并把全部差异称为有限样本误差（平滑在零原子处有偏）。
- **Wasserstein-1**：右支撑无界时，窗口外质量不足以控制尾误差；需附一阶尾矩控制或数值界，并写明如何用报告的**二阶尾矩**推出该控制。

### E2（秩阈值与下边缘相图，图 2）

- **目的**：$c$ 跨过 $p_{\rm multi}=1-e^{-1}$（多项）与 $p_{\rm res}=1$（残差）时的切换。
- **设置**：精确均匀权重；$c\in[0.35,1.15]$ 约 10–12 点，$0.6321$ 与 $1$ 附近加密。
- **Part A（count-only）**：零质量 $=(d-M_N)_+/d$（高斯单位总体下 $\operatorname{rank}(S_r)=\min(d,M_N)$ a.s.），$N=10^4$、数百次重复、零特征值分解；**不要用任意特征值阈值估零质量**（临界附近会造假象）。
- **Part B（少量矩阵）**：$N=1000$、每点 10–20 次；用较小 Gram/SVD 求正特征值（$B_N=\frac1{\sqrt N}Z_{I_N}\operatorname{diag}(\sqrt{n_i}:i\in I_N)$，取 $B_NB_N^\top$ 与 $B_N^\top B_N$ 中较小者）；报告 $\lambda_{\min}^+$ 中位数与四分位区间；图例三级分清（普适下界 / 极限支撑下沿 / 有限样本 $\lambda_{\min}^+$）；临界附近用已知秩定位正谱，避免浮点零当非零；不拟合临界缩放指数。
- **通过判据**：Part A 贴公式（临界带平滑如实标注）；Part B 中位数不低于基准（临界附近允许有限尺寸下弯）。
- **输出物**：`output/E2_atom.csv`、`output/E2_edge.csv` + 双面板图。
